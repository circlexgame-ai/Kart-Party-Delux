## 📌 About

Kart Party Deluxe is a kart racing game focused on competitive racing, unique tracks, special items and exciting game modes.

The project aims to deliver an entertaining racing experience with customizable gameplay, challenging opponents and varied environments.

## ✨ Features

- 🏁 Multiple racing tracks
- 🎮 Multiple game modes
- 💨 Drifting and mini-turbo mechanics
- 🎯 Power-ups and special items
- 🤖 AI-controlled opponents
- 🏆 Tournament and time trial modes
- ⚙️ Customizable gameplay settings
- 📱 Touch control support

## 🗺️ Tracks

| Track | Description |
|---|---|
| Sunshine Shores | A sunny beach racing environment |
| Rainbow Road | A colorful and challenging racing track |
| Magma Mountain | Volcanic track — development planned |
| Night City | Night-time urban track — planned |

*Track availability depends on the current project version.*

## 🎮 Game Modes

- **Race** — Compete against AI opponents.
- **Cup** — Compete across multiple races.
- **Time Trial** — Beat your personal records.
- **Item-Free Race** — Race without power-ups.
- **Crazy Items** — Experience unpredictable item gameplay.
